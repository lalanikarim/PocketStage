Every patch of every loaded soundfont, named by the fonts themselves (GET /api/patches — never a hand-typed table). ▶ auditions on a private channel for 0.5 s and changes nothing at all; ★ makes it the live voice; 🥁 sets the pad kit (persists with Save). Fonts are loaded from ~/.pocketstage/soundfonts at boot.

DAW keys

DAW-mode bindings live in one global file (the keyboard, not the song) and apply instantly — no restart. A remap while a key is held can drop that key's note-off. PRESET instrument routing is fixed by design. Overlay buttons above are the escape hatch: they work even if every binding is gone.

Device map

What the unit physically transmits (measured wire truth, see specs/device-maps/): pad base note, knob/fader CCs, channels. Edits hot-reload into the MIDI feeder immediately — wrong values misroute physical controls, but factory defaults are one click away. This is the device layer; semantic bindings live under “DAW keys”.
